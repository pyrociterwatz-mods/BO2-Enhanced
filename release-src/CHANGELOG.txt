Blood Omen 2 Enhanced - changes
===============================

1.0.2
- The public launcher no longer contains the crash logger (it ran the game under a debugger, which anti-virus heuristics
  flagged). "Open log folder" in the launch window shows the sound engine's logs. Testers get a separate build with the logger.

1.0.1
- Setup no longer carries the launcher, the DLLs and the patch data inside itself: they come as separate files in the
  "files" folder (extract the whole zip before running setup). Anti-virus heuristics flagged the all-in-one setup.
- Setup, launcher and bo2skipui.dll carry product name, description and version details.

1.0
- First public release, renamed from "Blood Omen 2 Cutscene Skip + Sound Fix" (test builds 0.2 - 0.9.13).
- Log folder is now Documents\Blood Omen 2 Enhanced logs.
- Trainer options: choosing Trainer opens a list where god mode, walk on water and each debug display can be turned
  on or off.
- The launch window and the Trainer list scale with Windows display scaling (text was cut off above 100%).
- GOG version supported (its game files are identical to Steam's); setup finds GOG installs, and "bo2.exe -setup"
  (GOG Galaxy's Settings entry) opens the game's own settings window.
